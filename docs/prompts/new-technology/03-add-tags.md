Generate the navigation tag dictionary for ONE technology.

Technology:

Node.js

Input:

```
data/generated/node.json

data/categories/node.json
```

Output:

```
data/tags/node.json
```

Use only the approved category dictionary.

Do not modify categories.

Do not modify questions.

Do not modify answers.

The dictionary should contain approximately 80–100 high-quality navigation tags.
