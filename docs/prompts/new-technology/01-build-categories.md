# Goal

Generate a category dictionary for ONE technology.

Technology:

Node.js

---

# Existing Categories

Read:

```
docs/categories.md
```

If the technology already exists:

- reuse the existing categories.

If the technology does not exist:

- design a complete category taxonomy;
- follow the same structure and level of granularity as the existing technologies;
- write the new categories into the appropriate section of `docs/categories.md`.

After that generate:

```
data/categories/node.json
```

Do NOT generate categories for any other technology.
