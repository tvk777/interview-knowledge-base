Крупные этапы проекта
Этап 1. Подготовить исходные данные

Вход:

original/
    javascript.json
    react.json
    nextjs.json
    ...

Это оригинальные JSON-файлы без изменений.

Результат:

Исходные данные готовы к обработке

Этап 2. Построить конвейер обработки (Data Pipeline)

Это отдельная папка.

scripts/

normalize.ts
categorize.ts
translate.ts
validate.ts
build.ts

Именно этот pipeline один раз обрабатывает исходные данные.

React его больше никогда не касается.

Этап 3. Создать Enriched JSON

Это главный этап проекта.

Из

{
    "question":"...",
    "answerBlocks":[...]
}

получить

{
    id,
    category,
    subcategory,
    tags,

    difficulty,

    question:{
        en,
        uk
    },

    answer:{
        en,
        uk
    }
}

Именно этот JSON становится единственным источником данных для приложения.

Этап 4. React-приложение

React ничего не преобразует.

Он просто читает

data/questions.json

и отображает данные.

Этап 5. Возможности приложения

На основе Enriched JSON реализуются:

дерево категорий;
дерево подкатегорий;
список вопросов;
поиск;
карточка вопроса;
облако тегов;
глоссарий;
переключение языка;
избранное;
история просмотра.
