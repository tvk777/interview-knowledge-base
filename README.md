# Interview Knowledge Base

An AI-powered knowledge base for software engineering interview preparation.

## Project Structure

```text
data/        # Generated knowledge base data
prompts/     # AI prompts
scripts/     # Utility scripts
src/         # Data generation scripts
frontend/    # Next.js application
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
